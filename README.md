# 🧠 ควิซกวนประสาท เกรียนสุด IQ พุ่ง!

เกมควิซกวนประสาทแบบไฟล์เดียว (HTML + CSS + JS)

## เล่นยังไง
- ตอบถูก: +9,999 IQ
- ตอบผิด: -5,000 IQ
- เริ่มต้นที่ 100 IQ

## วิธีเล่น
เปิดไฟล์ `index.html` ในเบราว์เซอร์เลย

## คุณสมบัติ
- ตัวเลือกสลับตำแหน่งทุกครั้ง
- ปุ่มผิดมี animation กระตุก
- Popup เฉลยแบบเกรียน
- คำนวณ IQ สุดท้ายแบบสุดโต่ง
